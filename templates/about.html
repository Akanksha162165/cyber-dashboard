🛡️ Cyber Threat Intelligence Dashboard

A full-stack web application that collects, processes, and visualises cybersecurity incident data to help analysts identify attack patterns, high-risk sectors, and geographic threat origins — the same approach used by IBM X-Force, CISA, and enterprise Security Operations Centers worldwide.

✨ Key Features

  • 🔐 Role-based login system (Admin / Analyst / Guest) with Flask session management
  • 📊 6 interactive Chart.js visualisations — doughnut, line, and bar charts
  • 🌍 World map showing attack origins and targets using bubble charts
  • 🔍 Real-time filters by attack type, sector, severity, and country
  • 📋 Paginated incident table with live search across 2,000 records
  • ⬇️ CSV export of filtered data for offline analysis
  • 🚨 Alert system showing active critical/high-severity ongoing incidents
  • 🌙 Dark / Light mode toggle for accessibility
  • 📱 Fully responsive — works on mobile, tablet, and desktop
  • ⚡ REST API with 6 endpoints, supporting filters and pagination

☁️ Deployment Guide

1. GitHub — Push all project files to a GitHub repository.
2. Render.com — Connect your repo. Set Build Command to:
pip install -r requirements.txt && python scripts/generate_sample_data.py && python scripts/clean_data.py
Set Start Command to: gunicorn app:app
3. Deploy — Click Deploy. Your live URL will be ready in ~2 minutes.
